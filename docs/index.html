// A workflow with a contract.
type Ticket {
  category: "billing" | "bug" | "question"
  needs_review: Bool
}

task classify(message: String) -> Ticket {
  model: local
  context: [policy]
  prompt: "Classify: {{message}}"
  mock: { category: "billing", needs_review: false }
}

flow main {
  let ticket = classify("I was charged twice.")
  print ticket
}

A little structure goes a long way

More understanding.

A readable program connects what you ask, what the model sees, and what your application does next.

01 / DEFINE

Make the contract explicit.

Describe the result with types. Validate model output before the workflow can use it. Represent missing information with null.

email: String?
02 / BOUND

Decide what can happen.

Attach named context. Limit model attempts. Set request timeouts and grant file access only to selected directories.

hailey run main.hailey --max-calls 3
03 / INSPECT

Keep a record you can read.

Opt into a trace with prompts, responses, usage, and errors. Replay it without making another inference request.

hailey inspect first.trace.json
