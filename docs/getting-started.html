Getting started

Install the CLI, run an offline workflow, and record your first trace in a few minutes.

Before you begin

You need Node.js 22 or later and npm. Hailey runs on macOS, Linux, and Windows. There is no compiler toolchain to install and no third-party runtime dependency. The offline starter does not need a model account.

node --version
npm --version

1. Install Hailey

The recommended installation uses the versioned package attached to the GitHub release. This avoids depending on an npm registry publication.

npm install -g https://github.com/Malanaa/Hailey/releases/download/v0.1.0/hailey-lang-0.1.0.tgz
hailey version

The version command should print 0.1.0. If your npm global directory is not writable, use a Node version manager or the one-off command below. Avoid changing system directory permissions to install Hailey.

Run without a global installation

npx --yes --package=https://github.com/Malanaa/Hailey/releases/download/v0.1.0/hailey-lang-0.1.0.tgz hailey --help

Install from Git

This option also requires Git. Pin a tag when reproducibility matters.

npm install -g git+https://github.com/Malanaa/Hailey.git#v0.1.0

Download and verify

Download hailey-lang-0.1.0.tgz and SHA256SUMS.txt from the release page. Compare the archive's SHA-256 digest with the checksum file, then install the local archive.

# macOS
shasum -a 256 hailey-lang-0.1.0.tgz

# Linux
sha256sum hailey-lang-0.1.0.tgz

# PowerShell
Get-FileHash .\hailey-lang-0.1.0.tgz -Algorithm SHA256

# All platforms
npm install -g ./hailey-lang-0.1.0.tgz

2. Create your first program

hailey init hello-hailey
hailey check hello-hailey/main.hailey
hailey run hello-hailey/main.hailey
hailey test hello-hailey/main.hailey

The initializer creates main.hailey in the selected directory. It refuses to overwrite an existing program. The run prints a ticket object followed by Route to accounts. The test prints PASS billing.

What the starter provesThe mock provider returns the fixture declared in the task. It demonstrates parsing, validation, branching, and tests. It does not classify new messages or measure model quality.

3. Record what happened

hailey run hello-hailey/main.hailey --trace first.trace.json
hailey inspect first.trace.json
hailey run hello-hailey/main.hailey --replay first.trace.json

The first command creates a new trace. The second prints its contents. The third checks the program and replays the recorded result. Use a new trace filename for each recording because Hailey does not overwrite existing files.

4. Connect a model when you are ready

Follow Models and providers to configure an endpoint, a model name, and an environment variable for credentials. Live calls can incur charges. Keep the offline fixture while developing your workflow, then test real examples against the chosen model.

Run from source

git clone https://github.com/Malanaa/Hailey.git
cd Hailey
node bin/hailey.js run examples/triage.hailey
npm test

Installation troubleshooting

SymptomWhat to check
hailey: command not foundRestart the terminal and confirm the npm global executable directory is on PATH. Try the npx command to avoid a global install.
Unsupported Node versionRun node --version. Use Node.js 22 or later.
Download returns 404Check the release URL, version, and archive name. Use the Git tag installation if you prefer.
PowerShell blocks npm.ps1Use npm.cmd and npx.cmd through your existing approved shell configuration.
File already existsThe initializer and trace writer refuse overwrites. Choose a new project directory or trace filename.
