Architecture and limits

Understand the implementation, the guarantees, and the deliberate boundaries of the first release.

How execution works

01 / ParseSource → AST
02 / CheckNames + schemas
03 / ExecuteSequential workflow
04 / InspectResults + trace

Hailey is an interpreter implemented in JavaScript. It does not translate a program into JavaScript and execute it with eval. The parser builds a small syntax tree and the runtime evaluates the supported nodes directly.

Parsing

The lexer recognizes identifiers, constants, comments, and symbols. Tokens retain line and column positions. A recursive descent parser builds declarations and expressions. Binary operators use explicit precedence rules.

Checking

The checker resolves declarations, rejects unknown settings, derives JSON Schemas, validates mock fixtures, and checks workflow references. Dynamic values are validated at execution boundaries. This is deliberately smaller than a full general purpose static type system.

Execution

A flow evaluates sequential statements in lexical scopes. Tasks render messages, attach explicit context, check the attempt budget, call a provider, validate the response, and append trace events. Retry behavior is bounded and visible.

Tracing

The runtime accumulates an in-memory trace even when no file recording is requested. The CLI writes it only when given a new --trace path. Replay replaces model and file effects with recorded events after checking fingerprints.

Design choices

ChoiceReason
One small languageKeep model configuration, contracts, context, and workflow close together
Explicit fixturesMake first runs and workflow tests reproducible without a provider account
Sequential executionKeep cost, order, and failure behavior straightforward in the first release
Required nullable fieldsRepresent missing values without silently dropping schema fields
Unknown cost remains unknownAvoid showing zero when usage or prices were not available
Strict source matching for replayPrevent accidental use of recordings from another program version
No external runtime dependenciesKeep installation, inspection, and packaging simple

What this release guarantees

  • Values returned from tasks are checked against the declared structural schema
  • No model attempt begins after the configured attempt count is reached
  • Recorded replay does not initiate fresh inference calls
  • Successful file reads require an allowed canonical directory
  • Unknown cost information is kept separate from known estimates

What it does not guarantee

  • That a structurally valid model answer is factually correct
  • That a provider honors a requested token limit or stops billing after a client timeout
  • That a prompt is immune to injection
  • That an editable trace is authentic evidence
  • That the interpreter is a security sandbox for hostile programs or concurrent filesystem attacks
  • That a new inference call will reproduce an earlier result

Current scope

Hailey v0.1 is useful for extraction, classification, and sequential AI pipelines. It has no autonomous agent loop, arbitrary tool plugins, network tools beyond model requests, streaming, persistent memory, vector search, training, automatic prompt optimization, full static inference, or hard dollar spending cap.

There is no automatic correction prompt on a retry. A retry repeats the same task request. There is no automatic model fallback or provider discovery. These choices keep actual execution close to what the source says.

Possible next steps

These are directions to investigate, not shipped features or promised dates.

  1. Dataset evaluation with repeatable quality and cost reports
  2. Editor support with diagnostics and syntax highlighting
  3. A local trace viewer for comparing executions
  4. Explicit tool definitions with stronger capability isolation
  5. Streaming and provider adapters driven by concrete use cases

About this documentation site

These pages are static HTML served directly from docs/. They use the requested Tailwind browser CDN, local CSS for the core layout, and a small JavaScript file for navigation search and code copying. The pages remain readable if the CDN is unavailable. Tailwind describes the browser CDN as a development option. A future production asset build can remove that runtime dependency.
